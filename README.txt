ContentFlow Reframe — primera versión

Qué hace
- Adapta un video a vertical (9:16), cuadrado (1:1) u horizontal (16:9), eligiendo una sola salida por conversión.
- Conserva el contenido principal centrado por defecto y rellena el espacio sobrante con una versión ampliada y difuminada del propio video.
- Permite ajustar el recorte de forma simétrica desde el centro con dos controles sencillos.
- Permite un nombre de salida opcional. Si se deja vacío, conserva el nombre del archivo original y añade -vertical, -cuadrado o -horizontal.
- Descarga directa del MP4, sin crear ZIP.
- Mantiene las tres vistas previas visibles durante la conversión.
- Mantiene audio cuando el archivo de origen contiene audio compatible.

Uso
1. Publica el contenido de esta carpeta en GitHub Pages o en un sitio estático con HTTPS.
2. Introduce la clave de acceso de tu producto.
3. Selecciona un video y elige vertical, cuadrado u horizontal.
4. Opcionalmente, ajusta el encuadre con los controles.
5. Pulsa Crear video y descarga el MP4 al terminar.

Notas importantes
- El procesamiento se realiza en el navegador del usuario; no se envía el video a un servidor de procesamiento propio. Se necesita internet para cargar el motor FFmpeg desde el CDN.
- Mantén la página abierta y la pantalla encendida durante la conversión.
- Límite configurado: 3 minutos y 30 segundos. La compatibilidad y el rendimiento dependen del dispositivo y del video.
- Esta primera versión conserva el sistema de clave de acceso existente de la versión anterior.
- Antes de vender/publicar, verifica licencia y obligaciones de distribución de FFmpeg.wasm (GPL-2.0-or-later), clave de acceso, y realiza pruebas reales en móvil y escritorio.
- El texto de interfaz es español en esta primera versión; la estructura bilingüe queda para una actualización posterior.
